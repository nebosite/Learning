# Line Counter

A simple command-line tool built with Node.js and TypeScript that counts the number of lines in a file.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Build the project:
```bash
npm run build
```

## Usage

You can run the application in two ways:

1. Using npm start:
```bash
npm start -- <filename>
```

2. Using ts-node for development:
```bash
npm run dev -- <filename>
```

Example:
```bash
npm start -- example.txt
```

The program will output the number of lines in the specified file.
